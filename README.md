# Hotel-Management-Database-Using-SQL
Advanced SQL project demonstrating joins, aggregate functions, subqueries, views and CTEs in a restaurant database system.

##  Description
This project is a comprehensive Hotel Management Database built using SQL. It demonstrates advanced database concepts including table creation, data insertion, joins, aggregate functions, subqueries, views, and Common Table Expressions (CTEs).

##  Technologies Used
- MySQL
- SQL

## Features
- Created multiple relational tables
- Implemented Primary Key and Foreign Key constraints
- Inserted sample data into all tables
- Performed data retrieval using SQL queries

##  SQL Concepts Covered
- CREATE TABLE & INSERT INTO
- SELECT queries with WHERE clause
- INNER JOIN, LEFT JOIN , RIGHT JOIN , FULL OUTER JOIN
- GROUP BY 
- Aggregate Functions (SUM, COUNT, AVG)
- Subqueries
- Views
- CTEs (Common Table Expressions)

##  Sample Operations
- Calculate total bill per order
- Find customers with high spending
- Retrieve data using joins from multiple tables
- Use subqueries for filtering
- Create and query views
- Use CTEs for better query readability

##  How to Run
1. Open MySQL Workbench
2. Run the SQL file (Project.sql)
3. Execute queries step by step
4. View outputs
